# PLATFORM-06 CI-safe GitHub Actions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a minimal Ubuntu GitHub Actions workflow and a repo-owned CI safety gate that executes the already validated `npm run test:platform` path without accessing real products or runtimes.

**Architecture:** `scripts/platform/ci-safety-check.mjs` parses the workflow with YAML and validates executable CI/package command surfaces against a denylist and required Synthetic-only invariants. `npm run test:ci` composes `ci:safety`, `validate`, and the existing `test:platform`; the workflow installs with `npm ci --registry=https://registry.npmjs.org/`, installs only Chromium, then invokes that single command.

**Tech Stack:** GitHub Actions, `actions/checkout@v4`, `actions/setup-node@v4`, `actions/upload-artifact@v4`, Node.js 24, npm, YAML parser, Node built-in test runner, existing Playwright/Python platform commands.

## Global Constraints

- Implement PLATFORM-06 only; do not implement Environment Profiles, Result Aggregation, Flaky Policy, Governance, or Agent Invocation.
- Use `ubuntu-latest`; do not run Avalonia, Appium, FlaUI, WinAppDriver, real DLL, real database, desktop runtime, or real Web/API tests.
- Use `npm ci`, not `npm install`, and temporarily override the local domestic registry only in CI.
- Install only Chromium with official Linux-compatible Playwright installation.
- Keep `npm run test:platform` as the bottom-level platform command; `test:ci` adds CI safety and static validation without duplicating test logic.
- Preserve Known Bug semantics: product `ExecutionStatus=FAIL`, `EXPECT_PRODUCT_FAIL`, acceptance `GateStatus=PASS`, and CI remains green.
- Upload only ignored, Synthetic-only, sanitized artifacts with seven-day retention and `if: always()`.
- Preserve all existing user changes and untracked files; stage only an explicit PLATFORM-06 allowlist; do not push.
