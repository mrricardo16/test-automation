# Execution Policy

Every future run uses a new `runs/<RunId>/` directory and includes Handoff Intake, Runtime Health, Coverage, TestCase Review, Execution, Evidence, Defect, Reconciliation, Regression, and Final Report records.

Execution requires HandoffIntegrity=PASS, HandoffValidation=PASS, black-box integrity, approved credentials/data, and automation capability. A blocked gate remains BLOCKED.
