# TestCase TC-RSS-SM-CRUD-001

- TestCaseId：`TC-RSS-SM-CRUD-001`
- 名称：系统管理测试数据 CRUD、状态与关联清理
- 依据：`功能_02_Web管理端_系统管理(1).md`
- 执行方式：独立浏览器会话 + 页面语义定位
- 数据前缀：`RSS-AUTO-`
- 账号边界：`sa` 仅用于准备普通管理员；正式 CRUD 使用普通管理员

## 前置条件

1. Web 前端和 API 已启动。
2. 用 `sa` 创建普通管理员及其系统管理权限。
3. 普通管理员成功登录并可访问用户、角色、菜单、字典、外部系统配置。

## 步骤与预期

1. 查询既有数据，确认查询条件、空结果和列表刷新可用。
2. 创建测试角色、测试用户、测试菜单和测试字典；保存后重新查询可见。
3. 修改测试角色、测试用户、测试菜单和测试字典；重新查询显示修改值。
4. 验证用户启用/禁用、用户与角色关联、角色与菜单关联。
5. 对可删除测试数据执行删除，确认二次确认、成功提示、列表消失及关联清理。
6. 外部系统配置仅在字段和保存契约可安全验证时使用临时数据；否则记录 `BLOCKED`，不修改既有运行配置。

## 状态规则

仅使用 `PASS`、`FAIL`、`ERROR`、`BLOCKED`、`MANUAL`、`SKIPPED`。任何“保存成功”但刷新后查询不到的数据，按实际一致性结果判定，不按提示单独判定通过。
