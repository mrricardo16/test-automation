# TC-RSS-FL-AUTH-06：sa 与普通账号权限对照

| 字段 | 内容 |
| --- | --- |
| TestCaseId | `TC-RSS-FL-AUTH-06` |
| 依据条目 | `FL-AUTH-06`；`SM-USER-07`、`SM-ROLE-05` |
| 类型 | P0 权限对照 |
| 操作 | 记录并暂时移除 `sa` 角色；用 `sa` 登录核对全量 PC 菜单；用普通账号移除全部角色后登录核对空菜单；恢复原关联 |
