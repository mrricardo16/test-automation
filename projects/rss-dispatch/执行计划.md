# RSS调度 Web 测试执行计划

> **For agentic workers:** 本计划仅用于当前项目测试执行；所有产物必须保存在 `E:/automated-testing/RSS调度`。

**Goal:** 在真实本地 RSS 调度系统上验证 SA 登录和用户管理查询页面的可用性，并保留可追溯证据。

**Architecture:** 使用独立的 Playwright 配置和项目目录，凭据仅由执行进程注入。测试依据中的用户管理条目映射到项目专用 TestCase；页面截图、失败信息和报告均写入本目录。

**Tech Stack:** Playwright Test、Chromium、TypeScript、UTF-8 Markdown/JSON。

## Global Constraints

- 只测试 `http://localhost:8223` 真实前端，不修改产品代码。
- 账号为 `sa`；密码只通过进程环境变量传递，不写入文件。
- 使用状态：`PASS`、`FAIL`、`ERROR`、`BLOCKED`、`MANUAL`、`SKIPPED`。
- 优先使用角色、标签、测试 id 和稳定语义定位器；不使用固定坐标点击。
- 附件依据中的角色、菜单、字典、外部系统配置目前是待补范围，本次标记为 `SKIPPED`，不执行。
