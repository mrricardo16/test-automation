# 测试工作流是否正常运行

- Project slug: `test-workflow`
- Purpose: 归档本次测试工作流自身的执行报告和正式输出。
- Scope: 平台质量门禁、合成测试、文档/流程产物及其执行结果。

目录约定：

- `projects/test-workflow/reports/`：本项目的报告和执行摘要。
- `projects/test-workflow/outputs/`：本项目的正式文档、表格、流程图等输出。
- `projects/test-workflow/artifacts/`：运行时截图、Trace、日志和其他证据；默认被 Git 忽略。

本目录不复制测试源码或 TestCase。源码仍位于仓库的 `tests/` 和 `test-cases/` 目录。
