## 执行约定

- 正式执行状态仅使用 PASS、FAIL、ERROR、BLOCKED、MANUAL、SKIPPED。
- FAIL：真实交互完成但结果不符合预期。
- ERROR：测试脚本、定位、浏览器或执行基础设施错误。
- BLOCKED：服务、账号、权限或其他前置条件缺失。
- 每条正式用例保留预期截图和结果截图；失败/错误额外保留 Trace、日志或错误栈。
- 数据库断言只允许只读查询；密码字段不得输出到报告或证据。
- 测试数据不得删除当前登录账号、内置管理员、内置角色及系统类型字典。
