# TC-SM-SYSTEM-MANAGEMENT-001：系统管理真实 Web 测试用例

> 本文件是与 system-management-test-cases.xlsx 对应的 Markdown 测试用例版本，共 28 条设计用例。执行结果需在执行明细中回填，不能用设计内容代替真实执行证据。

## 适用范围与公共前置条件

- 目标：真实 Web 系统管理页面，包括用户、角色、菜单、字典、外部系统配置及最终权限核验。
- 环境：localhost:8223 真实运行实例。
- 浏览器：Chromium，1280×720。
- 账号：SA 账号通过运行环境注入；本文不保存密码或密钥。
- 版本：源码与运行实例同版。
- 自动化：优先使用 Playwright；自动化文件为 tests/web/real-project/TC_SM_SYSTEM_MANAGEMENT_001.spec.ts。
- 证据：每条正式用例必须保留预期截图和结果截图；FAIL/ERROR/BLOCKED 还要保留错误截图、Trace、日志或错误栈。
- 清理：菜单、角色、外部系统配置和可删除用户数据按用例清理；系统类型字典删除必须复核仍存在。

## 状态与分类约定

- 最终状态仅使用：PASS、FAIL、ERROR、BLOCKED、MANUAL、SKIPPED。
- FAIL：页面交互真实完成，但实际结果不符合预期。
- ERROR：测试脚本、定位、浏览器或执行基础设施错误。
- BLOCKED：服务、账号、权限或其他前置条件缺失，未完成验证。
- MANUAL：无法可靠自动化的视觉或交互断言。

## 优先级定义

| 优先级 | 定义 |
| --- | --- |
| P0 | 阻断核心业务或权限边界；失败应停止发布。 |
| P1 | 核心业务功能；失败会显著影响主流程。 |
| P2 | 重要功能或数据维护，通常有替代路径或影响范围较小。 |
| P3 | 低风险、展示性或补充性验证。 |
