# Coverage and traceability

Each row links Module/Feature/Rule/Flow/API/Validation/State, Source Risk, Business Risk, Priority, ExpectedBasis, layers, TestCaseId, final status, reconciliation, Evidence, and limitation. Track Business, Rule, Flow, Validation, State, API, Permission, Automation, Execution and optional Code Coverage independently. Trace SourceEvidence → Coverage → TestCase → result → Evidence → defect. Code line/method/branch coverage is a signal, not business coverage.
