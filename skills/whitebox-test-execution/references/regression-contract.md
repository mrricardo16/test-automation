# Regression contract

Final status is one of `PASS`, `FAIL`, `ERROR`, `BLOCKED`, `MANUAL`, `NOT_APPLICABLE`, `SKIPPED`. Reconciliation is separately `COVERED_PASS`, `COVERED_FAIL`, `COVERED_ERROR`, `BLOCKED`, `MANUAL_PENDING`, `NOT_APPLICABLE`, `NOT_COVERED`; P0 `NOT_COVERED` blocks completion. Supported modes: `FULL_WHITEBOX_REGRESSION`, `MODULE_REGRESSION`, `P0_ONLY`, `FAILED_RERUN`, `SOURCE_CHANGE_IMPACT`, `SINGLE_TESTCASE`. Source Change Impact maps changed source/commit/diff to IDs, TestCases, and incremental scope; it never replaces the initial baseline. `CODE_COVERAGE_NON_INVASIVE` means only existing report read or test-owned output/configuration; never product changes and never a replacement for business coverage.
