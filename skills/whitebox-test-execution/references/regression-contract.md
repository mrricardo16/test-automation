# Regression contract

`ExecutionStatus` is one of `PASS`, `FAIL`, `ERROR`, `BLOCKED`, `MANUAL`, or `SKIPPED`. `CoverageStatus` is separately `COVERED`, `PARTIAL`, `UNTESTED`, `MANUAL`, or `NOT_APPLICABLE`; P0 `UNTESTED`/`PARTIAL` blocks completion. `LegacyFieldAdapter` maps historical reconciliation values without rewriting them. Supported modes: `FULL_WHITEBOX_REGRESSION`, `MODULE_REGRESSION`, `P0_ONLY`, `FAILED_RERUN`, `SOURCE_CHANGE_IMPACT`, `SINGLE_TESTCASE`. Source Change Impact maps changed source/commit/diff to IDs, TestCases, and incremental scope; it never replaces the initial baseline. `CODE_COVERAGE_NON_INVASIVE` means only existing report read or test-owned output/configuration; never product changes and never a replacement for business coverage.
