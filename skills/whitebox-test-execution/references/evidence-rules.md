# Evidence rules

Unit/Integration evidence includes TestCaseId, layer, command, method, Expected, Actual, stack/error, duration, SourceEvidence. API adds method/path/status and sanitized response. Web failure/error adds screenshot, safe URL, failed step, Expected/Actual, trace when available, console/network context. Desktop records the equivalent safe evidence; Manual remains `MANUAL`. Map all evidence in `evidence-index.md`, preserve relative paths, and sanitize before retention.
